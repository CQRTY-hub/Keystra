# Keystra — Cookie policy

**Language:** English
**Version:** none — no separate version number is tracked for this text
**Status:** No Dutch version exists yet. There is no dedicated "cookie policy" page on the site today — this document compiles the cookie-related text that does exist: the consent banner, and the cookie preferences page. It does not yet list individual cookies, their purpose, or their retention period, which a full cookie policy would normally need.

---

## Consent banner (shown on first visit)

We only use cookies that are necessary to run the shop, unless you agree to more below.

Buttons offered: **Reject** / **Accept** — both the same size and style, so rejecting is exactly as easy as accepting.

## Cookie preferences page (reachable any time via the footer)

Change your mind any time. Withdrawing consent is exactly as easy as giving it.

Current status is shown as one of: "Accepted — non-essential cookies allowed", "Rejected — only necessary cookies", or "Not yet set".

Buttons offered: **Accept non-essential cookies** / **Reject non-essential cookies**.

## What is not yet written

No analytics or other optional script currently exists anywhere on the site. When one is added, it must be gated behind an accepted cookie choice — never loaded unconditionally. A full cookie policy (naming each cookie, its purpose, and how long it's kept) still needs to be written once there is something concrete to list.
